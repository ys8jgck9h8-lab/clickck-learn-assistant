# Fragenbestand

Hier können JSON-Exporte mit rechtmäßig nutzbaren Fragen abgelegt werden. Importiere sie mit `npm run import -- ./datei.json`. Jeder Datensatz benötigt mindestens `id`, `text` und `answers`. Eine Frage gilt nur als verifiziert, wenn die Quelle dies belegt und `verified: true` gesetzt wurde. Dieser Ordner enthält aktuell keine offiziellen Fragen.
